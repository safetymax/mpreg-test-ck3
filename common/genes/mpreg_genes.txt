# the female belly.
#
# IMPORTANT: reopening a specific template like this fully REPLACES it
# rather than merging field-by-field, so every field the template needs
# (index, the original female block) has to be repeated verbatim here
# alongside the new male block, or vanilla's own version silently breaks.
# See the correction below -- learned this the hard way.
#
# This depends on the character's skeleton actually having a bone/channel
# matching "bs_body_pregnant_1" -- which is exactly the piece that was
# missing from the custom mesh's rig and has since been copied over from
# the vanilla female pregnant armature.
